# Work Requirement 3 REST Principles Stress Test
In this work requirement, you will assess API behaviors and design claims against core RESTful principles. 
The focus is on evaluating whether given statements and scenarios are consistent with core REST design principles, 
and on reasoning about the consequences of design choices. No coding or API implementation is required.

Submission deadline: 29.10.2026, 12:00

## Objectives
* Identify REST principles in described API behaviors
* Assess whether design choices are consistent with core REST design principles
* Reason about the consequences of violating REST principles
* Explain architectural trade-offs clearly and precisely
